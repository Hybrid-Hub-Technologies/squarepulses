STEP 1️⃣  GET BINANCE API KEYS (5 minutes)
─────────────────────────────────────────
1. Go to https://www.binance.com
2. Account → API Management → Create API
3. Enable "Spot Trading" ONLY
4. Copy your API Key and Secret
5. Save them securely

STEP 2️⃣  ADD CREDENTIALS (1 minute)
──────────────────────────────────
Command:
  curl -X POST http://192.168.100.81:5000/api/trading/keys/add \
    -H 'Content-Type: application/json' \
    -d '{
      "accountName":"main",
      "apiKey":"YOUR_KEY_HERE",
      "apiSecret":"YOUR_SECRET_HERE",
      "environment":"mainnet"
    }'

Response:
  ✅ Credentials saved for account: main

STEP 3️⃣  START TRADING (Immediate)
──────────────────────────────────
Open chat with OpenClaw and say:
  "Buy 0.1 Bitcoin with $5 profit target"

OpenClaw will:
  ✅ Execute the trade
  ✅ Monitor automatically
  ✅ Close at profit target
  ✅ Notify you when done
